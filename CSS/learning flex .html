Flexbox must have a parent element with the display property set to flex or inline-flex.

Direct child elements of the flex container automatically becomes flex items.

.container { display: flex; flex-direction: column; background-color: DodgerBlue; } .container div { background-color: #f1f1f1; width: 100px; margin: 10px; padding: 10px; text-align: center; font-size: 30px; }
